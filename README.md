# 智域启算——基于 FPGA 的多传感器融合自主移动机器人

## 1. 项目简介

本项目面向复杂环境下的自主移动与智能巡检需求，设计了一套基于高云 GW5AT-60K FPGA 的多传感器融合自主移动机器人系统。

项目采用 FPGA 作为底层实时控制核心，结合多传感器感知、麦克纳姆轮运动控制、实时避障及路径点导航技术，构建模块化机器人控制平台。

在 FPGA 底层控制平台基础上，进一步扩展 BM1684 嵌入式 AI 主控与 Astra 深度相机，开展视觉目标识别和深度信息融合研究。

## 2. 系统硬件架构

- FPGA：Gowin GW5AT-60K
- 底盘：四轮麦克纳姆移动底盘
- 图像采集：OV5640 摄像头
- 姿态检测：IMU
- 测距模块：四路 VL53L0X ToF、HC-SR04 超声波
- 显示模块：HDMI
- AI 扩展平台：BM1684
- 深度相机：Orbbec Astra S

## 3. FPGA 核心功能

1. 麦克纳姆轮运动控制
2. 四路电机编码器反馈采集
3. IMU 姿态数据采集与航向角显示
4. OV5640 摄像头图像采集与 HDMI 显示
5. 多方向 ToF 测距与异常恢复机制
6. 超声波辅助测距
7. A5 实时避障控制
8. A6 路径点导航控制
9. 多传感器状态可视化

## 4. 技术路线

第一阶段：基于 GW5AT-60K FPGA 完成底层硬件控制平台设计与功能验证。

第二阶段：完成摄像头、IMU、ToF、超声波及编码器等多传感器接入。

第三阶段：开展实时避障、路径点导航与复杂场景运动控制优化。

第四阶段：扩展 BM1684 与 Astra 深度视觉系统，研究 AI 目标识别及深度信息融合。
